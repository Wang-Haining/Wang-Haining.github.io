Who wrote this? A stylometry lab

Guest lecture, Haining Wang (Indiana University). Python runs in your browser: no account, no install.

Waking up Python in your browser…
Downloading the Python engine (about 10 MB, once). Each case then loads its own data, and the packages it needs (NumPy, scikit-learn, matplotlib) the first time a step uses them. Please be patient on slow Wi-Fi.
LLM step: offline cache

Privacy: the analysis never leaves your browser. In Case 4 the page downloads the EBG texts from GitHub (raw.githubusercontent.com), which sees your IP address as in any download, and if you type the class passcode, the text you chose is sent through a class proxy to an AI model provider; otherwise nothing else is sent. Provenance and licences of every dataset: data notes.
