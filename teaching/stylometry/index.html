Who wrote this? A stylometry lab

A free, self-paced lab by Haining Wang, Indiana University. Python runs in your browser: no account, no install.

How to use this lab

  • Four short cases; pick any one from the tabs. Each takes about 15–20 minutes. You need no account and nothing to install.
  • Everything runs in your browser. Click the round ▶ next to a code box (or press Shift+Enter inside it), or use Run all.
  • Every code box is editable: change a number or a word and run it again. + Add a code cell adds your own; Reset code undoes your edits.
  • The green box at the top of each case says when it is ready. If it is red, it says what to try.

Privacy: nothing you type leaves your browser unless you choose an optional online step (for example, pasting text into a chatbot yourself).

Download the whole lab (.zip) — for teachers who want to host or archive a copy (needs any static web server; see the README inside).
